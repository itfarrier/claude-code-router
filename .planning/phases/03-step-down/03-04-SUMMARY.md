## Decisions Made

- **Capture in the seam, one hop, notice-owned reason:** the seam (fork-owned file) performs the capture so the parent pipeline gains only one argument — the narrowest FORK-SEAMS-compliant change; the reason is copied from the notice, never recomputed.
- **Electron-as-node runtime for the core tracer command:** plain `node --test` cannot load better-sqlite3 here, so the RED/GREEN core commands use the repo's Electron binary with ELECTRON_RUN_AS_NODE=1 — the same runtime `build/run-tests.mjs` resolves for the core unit suite and the same environment 03-VERIFICATION used for these exact pipeline tests. Recorded in the red evidence `command` fields.
- **Fixture projection via getDetail:** `requestLogRuntime.list` does not return routeTrace; the fresh-row id from the list poll is read back through `getDetail({ id })`, which attaches the persisted trace.
- **Normalized fixture timings:** hop `durationMs` → 1 and `startedOffsetMs` → seq·5 (a deterministic ladder), and the generated `/headers/x-client-request-id` value → `req-normalized-0`; every other trace field is the producer's own value, verified byte-identical across two runs.
