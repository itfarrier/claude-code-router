<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Claude request model string to createRouteExecutionPlan | The model name is untrusted and decides whether traffic leaves the parent attempt list. |
| Snapshot file to the request path | A local file can be edited between the writer and the reader. |
| Shelf opener to logs | The request can carry a message body and credentials that this path must not touch. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Spoofing | parseClassRequest | high | mitigate | Match the whole trimmed string. A following ASCII letter or digit does not open the class, so claude-opusplan and best-model stay on the parent plan. |
| T-01-02 | Tampering | readShelfSnapshot | medium | mitigate | Accept only the ShelfSnapshot field shape. A missing, unreadable, or invalid file returns undefined and applyShelf keeps the parent plan. |
| T-01-03 | Information disclosure | applyShelf | high | mitigate | The function arguments are the parent plan and the execution-plan input. Do not read a message body, and do not write credentials into the snapshot or a log line. |
</threat_model>
